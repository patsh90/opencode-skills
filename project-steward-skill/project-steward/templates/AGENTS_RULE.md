## Project workflow

This project is managed with the `project-steward` skill. Before changing anything in
this repository other than a typo, formatting or a comment, load that skill and follow
it. In short: read `ARCHITECTURE.md` and `MILESTONES.md`, update them if the work
changes the plan, and make sure a ticket in `tickets/` covers the work before editing
code. Answering questions and reading code do not need the skill.
